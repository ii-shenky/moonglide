# moonglide — где встать, чтобы снять самолёт на фоне Луны

*Planner for photographers: for an airport, a runway and a night, the map shows where to stand and when,
so that an aircraft on final approach crosses the Moon (or the Sun). Written with Claude Code; docs are in Russian.*

Рейсы не предсказываются — они опаздывают и меняют полосы. Предсказывается **геометрия**: глиссада — неподвижная
линия в небе, Луна считается точно. Стоя в нужной точке в нужное время, вы видите глиссаду через диск,
и каждый самолёт на заходе пройдёт по Луне. Аналог — PhotoPills, только «башня» — глиссада, и она есть
у каждой полосы в мире.

## Что показывает

- **Удачные окна** на 30–90 дней вперёд: когда тень глиссады ложится на сушу и самолёт нужного размера на фоне
  диска — днём, в сумерки и ночью (Луна днём тоже видна). Клик — карта на этот момент и лучшая точка.
- **Ближайшие даты от точки**: нажали на пляж — список окон на 60 дней по всем полосам аэропорта.
- **Схема прицела**: вы → самолёт (время, высота, расстояние) → диск (высота над горизонтом, азимут).
- Карта: на каждые 2 минуты суток — линия на земле (над морем — пунктиром), откуда глиссада видна через центр диска; ползунок — время,
  выбранная минута — полосой во всю ширину диска.
- Цвет линии — сколько займёт самолёт (A320) на фоне диска: меньше трети / целиком / до трёх дисков / больше.
  Целиком в диске — это километры до самолёта, то есть низкая Луна.
- Тап по карте (или «я здесь» по GPS) — когда из этой точки глиссада идёт по диску: окно по времени,
  где в этот момент самолёт (расстояние, высота, сколько до порога), доля диска для ATR 72 / A320 / B777,
  сколько длится пролёт (доли секунды — серия или видео), высота и азимут Луны, темнота неба.
- Луна и Солнце (для Солнца — только с сертифицированным фильтром).
- Ссылка на точку: `/#LCLK/22/2026-11-26/moon/34.97974,33.72830`. Кнопки «Ларнака / Пафос» — быстрый выбор.
- Инструкция для фотографа — `/help` (ссылка «как пользоваться» в шапке): принцип, легенда, разбор точки, поиск,
  какая полоса в работе, советы на месте.

## Запуск

Нужен Python 3.11 или новее (проверено на 3.11 и 3.15) и интернет при первом запуске.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m moonglide          # → http://localhost:8090
```

При первом запуске скачиваются в `~/.cache/moonglide` (или `$STATE_DIRECTORY`, или `--cache`):
эфемериды DE421 (17 МБ), полосы и аэропорты OurAirports (16 МБ), тайлы рельефа по мере надобности (5–10 МБ на 1°×1°).
GPS («я здесь») браузер даёт только по HTTPS или на localhost.

Тесты и проверки (данные для них скачиваются в `cache/` рядом с кодом):

```sh
.venv/bin/python -m unittest discover -s tests
.venv/bin/python tools/check_sky.py
.venv/bin/python tools/check_shadow.py
```

## Точность и чего нет

- Луна и Солнце — Skyfield + JPL DE421, с параллаксом из точки наблюдения и рефракцией. Сверка:
  `tools/check_sky.py` (быстрый путь против честного топоцентрического расчёта — до 0,5″) и
  `tools/check_shadow.py` (из найденных точек самолёт в пределах нескольких угловых секунд от центра Луны при
  радиусе диска ~1000″). Сценарии из ревью — `.venv/bin/python -m unittest discover -s tests`.
- Заход — по схеме полосы из `approaches.toml` (угол глиссады, высота над порогом, FAF и IF; сейчас там Ларнака и
  Пафос, свои правки — в `approaches.local.toml`), иначе прямая 3° от порога (15 м над порогом) на 18 км. Реальные заходы могут идти
  иначе (доворот на финал, другой угол) — сверка с треками ADS-B впереди.
- «Где стоять» — для камеры на 1,7 м над землёй. Рельеф учтён: перекрытие обзора самолёта и диска горами в каждый
  момент окна; пересечение луча с рельефом ищется точно, по клеткам сетки (узкие хребты и вершины между отсчётами
  не теряются). Здания — нет. Море — где рельеф ровно 0;
  озёра и солёные озёра не отсекаются. Где GLO-30 не выпущен — GLO-90.
- Не учтены: какая полоса в ходу (ветер), расписание, облачность, где можно стоять. **Не стойте на территории
  аэропорта и у военных объектов** (на Кипре — Декелия, Акротири).
