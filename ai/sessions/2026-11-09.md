# moonglide — где встать, чтобы снять самолёт на фоне Луны

Памятка для Claude Code. Собрана из обсуждения в чате.
Всё, что помечено «проверить», — предположение, а не установленный факт.
`moonglide` — рабочее название, может поменяться.

## Что строим

Планировщик для фотографов: для выбранного аэропорта и даты показывает на карте,
**где встать и во сколько**, чтобы самолёт на заходе (или взлёте) прошёл по диску Луны.

Рейсы не предсказываем: они опаздывают, меняют полосы и т. д. Предсказываем
**геометрию**: глиссада — неподвижная линия в небе, а положение Луны считается
точно на века вперёд. Самолёты по глиссаде идут потоком, так что, стоя в нужной
точке в нужное время, шанс поймать пролёт высокий.

Идея пришла от знакомого пользователя, который занимается астрофотографией.
Он — первый пользователь и источник требований.

Аналог для объяснения людям: PhotoPills показывает, где встать, чтобы Луна
оказалась за башней или маяком. Здесь «башня» — глиссада, и она есть
у каждой полосы в мире.

(Ларнака LCLK, Пафос LCPH): там есть приёмник
ADS-B (проект nebo), которым можно проверять предсказания.

## Ядро расчёта: «лунная тень» глиссады

1. Строим глиссаду как отрезок в пространстве: от порога полосы
   (координаты, высота порога + высота пролёта порога ~15 м, TCH) назад
   по курсу захода под углом 3°, примерно до 15–20 км от порога
   (это прямой участок финального захода, высота до ~1000 м). Проверить
   типичную длину прямого участка.
2. Для момента времени t берём направление на Луну (азимут, высоту).
3. Каждую точку глиссады проецируем **против** направления на Луну до
   пересечения с рельефом. Получаем линию на земле: стоя на ней, видишь
   глиссаду на фоне центра Луны. Учесть ширину диска (~0,5°): линия
   превращается в полосу.
4. Повторяем для t с шагом (например, минута) в пределах окна, когда Луна
   над горизонтом. Полосы «ползут» по земле — у каждой точки на карте своё время.

Тонкости:
- **Параллакс Луны.** Видимое положение Луны зависит от места наблюдателя,
  сдвиг до ~1° (два диска). Направление на Луну брать топоцентрическое для
  найденной точки на земле и уточнять итерациями: спроецировали с
  геоцентрическим направлением → пересчитали направление из найденной точки
  с её высотой → спроецировали заново. Проверить, за сколько итераций сходится.
- **Рефракция** у горизонта поднимает Луну, учитывать при низкой Луне.
- **Рельеф перекрывает обзор:** проверять прямую видимость от точки до
  самолёта и до Луны (гора между ними — точка не годится).
- **Видимый размер самолёта:** угловой размер = размах крыла / расстояние,
  сравнивать с диском Луны (~0,5°). Показывать «самолёт займёт ~N% диска».
  Типовые размахи брать по типу борта.
- **Длительность пролёта по диску** — доли секунды. Показывать её оценку
  (угловая скорость самолёта для этой точки), чтобы фотограф понимал,
  нужна ли серийная съёмка.

## Данные (все — проверить актуальность, лицензию и условия)

- **Луна, Солнце:** Python, библиотека skyfield + эфемериды JPL (DE421/DE440).
- **Полосы:** OurAirports (`runways.csv`): координаты и высоты порогов,
  курсы, смещённые пороги. Лицензия — public domain (проверить).
  nebo уже использует OurAirports.
- **Углы глиссад:** по умолчанию 3°. Точные углы и TCH — в национальных AIP;
  в США открыты данные FAA (CIFP). Возможность ручной поправки угла для полосы.
  Платные базы (Navigraph, Jeppesen) не используем.
- **Рельеф:** Copernicus DEM GLO-30 (глобальный, 30 м, бесплатный с указанием
  источника) или SRTM. Здания не учтены — честно писать об этом в интерфейсе.
- **Реальные коридоры и трафик (этап 2):** исторические данные ADS-B.
  adsb.lol, предположительно, выкладывает ежедневные архивы под открытой
  лицензией (ODbL) — проверить. По ним: где самолёты реально летят на
  финале, какая полоса в ходу, сколько бортов в нужный час, реальный угол
  снижения. У nebo есть свой архив треков вокруг Кипра — для калибровки.
- **Рабочая полоса:** зависит от ветра. Прогноз ветра — Open-Meteo
  (бесплатный, проверить условия), плюс статистика по истории ADS-B.
- **Где можно стоять:** OpenStreetMap — дороги, вода, частная территория,
  территория аэропортов, военные зоны (`landuse=military`).
  Военные зоны исключать полностью: на Кипре (Акротири и др.) за съёмку
  военных объектов задерживают.
- **Облачность и сумерки:** прогноз облачности (Open-Meteo), положение
  Солнца для оценки яркости неба.

- Один аэропорт (LCLK), одна полоса и направление захода, одна ночь.
- Глиссада 3° из OurAirports, рельеф из DEM, Луна из skyfield с параллаксом.
- Результат: карта (Leaflet + OSM) с полосами «где стоять», подписанными
  временем, плюс для выбранной точки: время, высота и расстояние до самолёта,
  доля диска, длительность пролёта, азимут и высота Луны.
- Без ветра, облаков, трафика и фильтров доступности.

Следом:
1. Любой аэропорт мира, выбор полосы, взлёты вдобавок к заходам.
2. Поиск по датам: «ближайшие удачные окна для этого аэропорта».
3. Фильтры доступности из OSM, исключение военных зон.
4. Рабочая полоса по прогнозу ветра, облачность.
